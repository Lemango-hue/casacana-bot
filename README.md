# Novela (título pendiente)

Repositorio de trabajo de una novela en español.

- `CLAUDE.md` explica cómo se trabaja aquí y qué hay en cada carpeta.
- `voz/muestras/` es donde van los textos del autor que sirven de referencia de voz.
- `registro/` guarda las decisiones del autor y el registro de quién escribió qué.
- `docs/investigacion/` contiene el informe previo sobre herramientas y flujo de trabajo.

El contenido anterior de este repositorio (un bot) está guardado en la rama `archivo-anterior`.

## 1. claude.ai (chat web / escritorio / móvil): dónde se activan y suben las Skills hoy

### Takeaway
Hoy las skills se gestionan en **Customize > Skills** (https://claude.ai/customize/skills), no en "Settings > Capabilities"; en Settings > Capabilities solo queda el interruptor previo **"Code execution and file creation"** (renombrado "Create and edit files" en el nuevo diseño de Settings), que debe estar activado. Una skill propia se sube como ZIP desde Customize > Skills > "+" > "+ Create skill" > "Upload a skill".

### Cited Findings
- VERIFIED — Ruta actual para activar: "Settings > Capabilities" y comprobar que "Code execution and file creation (called Create and edit files in the updated Settings layout) is enabled"; luego "Go to Customize > Skills" y "Toggle individual skills on or off as needed". — [Help Center: Use skills in Claude, "Updated over a week ago"](https://support.claude.com/en/articles/12512180-using-skills-in-claude)
- VERIFIED — "All of your skills are listed at **Customize > Skills** in claude.ai and the desktop app, including skills that came inside a plugin." Pestañas: **Your skills** (agrupadas en "Created by you", "From your organization", "Shared with you", "From Anthropic & Partners") y **Discover** (skills que puedes añadir). Se activa con **Turn on** en la fila o con el interruptor dentro de la skill. — [claude.com/docs: Skills overview](https://claude.com/docs/skills/overview)
- VERIFIED — Uso: describir la tarea y Claude carga la skill si coincide con su descripción; o escribir `/` en la caja de mensaje y elegir la skill. — [claude.com/docs: Skills overview](https://claude.com/docs/skills/overview)
- VERIFIED — Pasos para subir una skill propia: (1) crear la carpeta con la estructura; (2) empaquetarla como ZIP; (3) "Navigate to Customize > Skills"; (4) "click the "+" button, then "+ Create skill""; (5) "Select "Upload a skill""; (6) subir el ZIP; (7) aparece en la lista y se puede activar/desactivar. — [Help Center: Use skills in Claude](https://support.claude.com/en/articles/12512180-using-skills-in-claude)
- VERIFIED — Para explorar el directorio de skills: "Customize > Skills, click the "+" button, then choose "Browse skills""; al pulsar "Add" la skill queda en tu lista, activada por defecto; las skills del directorio son de solo lectura (para modificarlas: descargar copia, editar y subir como propia). Artículo fechado **September 25, 2026**. — [Help Center: Browse skills, connectors, and plugins in one directory](https://support.claude.com/en/articles/14328846-browse-skills-connectors-and-plugins-in-one-directory)
- VERIFIED — Estructura del ZIP: "The ZIP must contain the skill directory itself as its top level... a `SKILL.md` sitting at the root of the ZIP isn't recognized as a skill" (`my-skill.zip` → `my-skill/SKILL.md`). El nombre del directorio debe coincidir con el campo `name`. — [claude.com/docs: Create custom skills](https://claude.com/docs/skills/how-to)
- VERIFIED — Frontmatter obligatorio de `SKILL.md`: `name` (minúsculas, números y guiones, máx. 64 caracteres, igual al nombre de carpeta) y `description` (máx. 1.024 caracteres). Recomendación: SKILL.md de menos de 500 líneas. Carpetas opcionales: `references/`, `assets/`, `scripts/`. — [claude.com/docs: Create custom skills](https://claude.com/docs/skills/how-to)
- VERIFIED — `name` no puede contener las palabras reservadas `anthropic` ni `claude`, ni etiquetas XML. — [platform.claude.com: Agent Skills overview](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview)
- VERIFIED — Causas de fallo al subir: ZIP que excede el límite de tamaño, nombre de carpeta distinto del nombre de la skill, falta el archivo SKILL.md, caracteres inválidos en nombre o descripción. **La página no da la cifra del límite de tamaño.** — [Help Center: Use skills in Claude](https://support.claude.com/en/articles/12512180-using-skills-in-claude)

## 2. Plugins en claude.ai y Cowork; diferencia entre Skill, Plugin, Conector (MCP) y Proyecto

### Takeaway
Los plugins se añaden en **Customize > Plugins** (https://claude.ai/customize/plugins) en claude.ai o en la app de escritorio, pestaña **Discover** > **Add**; solo en planes de pago. Quedan guardados en la cuenta, por lo que también llegan a Cowork y a Claude Code. Un plugin es un paquete que agrupa skills + conectores MCP + comandos/agentes; una skill es un procedimiento; un conector da acceso a un servicio externo; un proyecto es conocimiento de fondo siempre cargado.

### Cited Findings
- VERIFIED — "A plugin packages skills, MCP connectors, and commands and agents so you can add them to Claude as one unit. You add plugins from **Customize > Plugins** in claude.ai or the Claude desktop app; **Customize** is the page that holds your connectors, skills, and plugins. Each plugin is saved to your account, so it's also available in Cowork and Claude Code without installing it again." — [claude.com/docs: Plugins](https://claude.com/docs/plugins/overview)
- VERIFIED — Tres formas de añadir en la página Plugins: **Discover** (seleccionar y pulsar **Add**), **Add > Add marketplace** (URL de un repositorio Git o `owner/repo`), **Add > Upload plugin** (`.zip` o `.plugin` con un `.claude-plugin/plugin.json`). — [claude.com/docs: Plugins](https://claude.com/docs/plugins/overview)
- VERIFIED — Pasos del Help Center: "open the Customize menu in the left sidebar" → "Open the Plugins tab" → "Open the Discover tab" → "Select the plugin you want, then click "Add."" En Cowork: "open the "Cowork" tab first, then open Customize." ("Updated over 3 weeks ago".) — [Help Center: Use plugins in Claude](https://support.claude.com/en/articles/13837440-use-plugins-in-claude)
- VERIFIED — Planes: "Plugins are available to all paid plans (Pro, Max, Ultra, Team, Enterprise)." — [Help Center: Use plugins in Claude](https://support.claude.com/en/articles/13837440-use-plugins-in-claude). Coincide con "The directory's plugins appear on Pro, Max, Ultra, Team, and Enterprise plans" — [claude.com/docs: Plugins](https://claude.com/docs/plugins/overview)
- VERIFIED — Dónde queda disponible tras instalar: "Chat on the web, desktop, and mobile: its skills, commands, and connectors are available in your conversations"; Cowork: se cargan en la siguiente tarea; Claude Code: "downloads as a synced plugin the next time you start a session signed in to the same account". "Plugins you install from the Claude Code command line stay on that machine and aren't added to your claude.ai account." — [claude.com/docs: Plugins](https://claude.com/docs/plugins/overview)
- VERIFIED — Cowork: "Open **Customize** in the sidebar, then select **Plugins**" → **Discover** → **Install**. "The default marketplace is Anthropic's official catalog; you can add other marketplaces by URL." — [claude.com/docs: Install plugins (Cowork)](https://claude.com/docs/cowork/guide/plugins)
- VERIFIED — Límites: paquete de plugin 200 MB sin comprimir, 5.000 archivos; archivo de repositorio marketplace 512 MB; 500 plugins por marketplace; 25 marketplaces añadidos por el usuario. — [claude.com/docs: Install plugins (Cowork)](https://claude.com/docs/cowork/guide/plugins); mismos 200 MB / 5.000 / 25 en [Plugin feature support across platforms](https://claude.com/docs/plugins/platform-support)
- VERIFIED — Tabla comparativa oficial: **Skills** = "Task-specific procedures that Claude loads when a request matches"; **Plugins** = "Packages that contain several skills together with connectors, commands, and agents, so that you add them as one unit"; **Projects** = "Background knowledge that's always loaded in that project's chats"; **MCP connectors** = "Connections that let Claude reach external services and data". — [claude.com/docs: Skills overview](https://claude.com/docs/skills/overview)
- VERIFIED — Qué componentes carga cada superficie: Skills → Chat, Cowork y Claude Code; Commands → en chat se cargan como skill; Agents y Hooks → ignorados en Chat, cargan en Cowork y Claude Code; ejecutables en `bin/` → el plugin "Can't be installed" en Chat ni Cowork. — [claude.com/docs: Plugin feature support across platforms](https://claude.com/docs/plugins/platform-support)
- VERIFIED — Añadir un plugin no añade ni conecta sus conectores: hay que abrir la pestaña **Connectors** del plugin y conectar cada uno. Las skills del plugin cargan aunque no se conecte nada. — [claude.com/docs: Plugins](https://claude.com/docs/plugins/overview)
- VERIFIED — Las skills de un plugin aparecen en Customize > Skills > Your skills con el nombre del plugin, y se activan/desactivan junto con el plugin. — [claude.com/docs: Skills overview](https://claude.com/docs/skills/overview)
- VERIFIED — Catálogo web público: `https://claude.com/plugins` tiene por título "Plugins | Claude Marketplace | Claude by Anthropic", encabezado "Add new capabilities to Claude"; mostraba 23 de **539** plugins, filtro "Works with" (Claude / Claude Code), y etiqueta "Anthropic verified" en la mayoría. No vi ninguno de escritura/libros entre los 23 visibles. — [claude.com/plugins](https://claude.com/plugins)
- VERIFIED — Los docs de Claude Code llaman a ese catálogo "Claude Marketplace" en `claude.com/marketplace/plugins`, y precisan: "Anthropic's directory is separate from these marketplaces. The directory is the catalog on claude.ai." — [code.claude.com: Anthropic's marketplaces](https://code.claude.com/docs/en/plugins/anthropic-marketplaces)
- VERIFIED — Crear un plugin propio: **Customize > Plugins > Add** → "Create with Claude" o "Create a plugin". — [claude.com/docs: Plugins](https://claude.com/docs/plugins/overview)

### Inferences
- Para escribir un libro, lo relevante de un plugin en chat son sus skills (y comandos, que en chat se comportan como skills); agentes y hooks solo aportan en Cowork/Claude Code.
- "Directory" (catálogo dentro de claude.ai, revisado por Anthropic) y "Marketplace" (repos Git de Claude Code + web claude.com/marketplace) son dos cosas emparentadas pero distintas; los nombres se mezclan en la documentación (la guía de Cowork llama "marketplace" a lo que la de plugins llama "directory").

## 3. Claude Code CLI / escritorio: /plugin, marketplaces, ~/.claude/skills, .claude/skills, instalar desde GitHub

### Takeaway
En terminal, los plugins se instalan con `/plugin` (pestañas Discover / Installed / Marketplaces / Errors) o `claude plugin install <plugin>@<marketplace>`; las skills sueltas son carpetas en `~/.claude/skills/<nombre>/SKILL.md` (personales) o `.claude/skills/<nombre>/SKILL.md` (del repositorio). Además, desde v2.1.273 las skills y plugins activados en la cuenta claude.ai se sincronizan solos al terminal.

### Cited Findings
- VERIFIED — Instalar: `/plugin install commit-commands@claude-plugins-official` abre el panel con los detalles; `/plugin` sin argumentos abre la pestaña **Discover**. Ámbitos: user (`~/.claude/settings.json`), project (`.claude/settings.json`, se confirma en git), local (`.claude/settings.local.json`). — [code.claude.com: Install and manage plugins](https://code.claude.com/docs/en/discover-plugins)
- VERIFIED — Añadir marketplace: `/plugin marketplace add owner/repo` (GitHub), URL git completa, ruta local o URL de `marketplace.json`; atajo `/plugin install <plugin> --marketplace owner/repo` (v2.1.275+). — [code.claude.com: Install and manage plugins](https://code.claude.com/docs/en/discover-plugins)
- VERIFIED — App de escritorio (pestaña Code, sesión local o SSH): botón **+** junto a la caja de mensaje → **Add plugins** (o **Plugins** → **Browse plugins** / **Manage plugins**). VS Code: escribir `/plugins`. — [code.claude.com: Install and manage plugins](https://code.claude.com/docs/en/discover-plugins)
- VERIFIED — Ubicaciones de skills: Personal `~/.claude/skills/<skill-name>/SKILL.md` ("All your projects on this machine, but not Cowork or cloud sessions"); Project `.claude/skills/<skill-name>/SKILL.md` ("Commit it so your team gets it too"); Plugin `<plugin>/skills/<skill-name>/SKILL.md` invocada como `/plugin-name:skill-name`; y "claude.ai account: Skills enabled for your claude.ai account". Prioridad: enterprise > personal > project. — [code.claude.com: Skills](https://code.claude.com/docs/en/skills)
- VERIFIED — "Custom commands have been merged into skills. Your existing `.claude/commands/` files keep working." Invocación: `/skill-name` o automática por la `description`. — [code.claude.com: Skills](https://code.claude.com/docs/en/skills)
- VERIFIED — Instalación manual de una skill (única receta explícita encontrada): "Copy the skill folder into `~/.claude/skills/`, so the file sits at `~/.claude/skills/my-skill/SKILL.md`, then start `claude` in any project." — [claude.com/docs: Create custom skills](https://claude.com/docs/skills/how-to)
- VERIFIED — Instalar las skills del repo oficial como plugin: `/plugin marketplace add anthropics/skills`, luego `/plugin install document-skills@anthropic-agent-skills` o `/plugin install example-skills@anthropic-agent-skills`. — [github.com/anthropics/skills (README)](https://github.com/anthropics/skills)
- VERIFIED — Sincronización desde claude.ai: "Enabled skills sync to Claude Code when you sign in with the same Claude account. This requires v2.1.273 or later"; `/skills` las muestra bajo "claude.ai sync"; sincronización unidireccional, al inicio de sesión y cada ~10 minutos; se desactiva con `syncClaudeAiSkills: false`; no sincroniza con API key ni Bedrock. — [Help Center: Use skills in Claude](https://support.claude.com/en/articles/12512180-using-skills-in-claude)

## 4. Claude Code en la web (sesiones cloud, claude.ai/code): qué se sincroniza y por qué "no veo ningún botón para instalar skills"

### Takeaway
En una sesión cloud **no existe interfaz para instalar**: `/plugin` solo funciona en terminal y la sesión "has no plugin browser". Las skills se cargan solas desde la cuenta claude.ai (se gestionan en https://claude.ai/customize/skills/yours, fuera de la pantalla de Code) o desde `.claude/skills/` del repositorio; el único "botón" dentro de la conversación es **Add** en una tarjeta de sugerencia de plugins que Claude puede mostrar. La VM es desechable: lo copiado a mano no es un método soportado ni persistente.

### Cited Findings
- VERIFIED — "A cloud session, including the browser at claude.ai/code, **has no plugin browser** and doesn't load the plugins you installed at user or local scope." — [code.claude.com: Install and manage plugins, pestaña "Cloud session"](https://code.claude.com/docs/en/discover-plugins)
- VERIFIED — "Commands that only run in the terminal interface, such as `/plugin` or `/resume`, aren't available" en sesiones cloud. — [code.claude.com: Use Claude Code in the cloud](https://code.claude.com/docs/en/claude-code-on-the-web). Igual en móvil: "commands that only run in the terminal interface, such as `/plugin` and `/resume`, don't work from the app". — [code.claude.com: Claude Code on mobile](https://code.claude.com/docs/en/mobile)
- VERIFIED — "Cowork sessions and cloud sessions... don't read `~/.claude/skills/` on your machine... Manage those skills at claude.ai/customize/skills/yours." Para que una skill personal esté disponible: "For Cowork sessions, cloud sessions, and cloud threads in a project, **enable the skill for your claude.ai account**"; "For cloud sessions, you can instead **commit the skill to the repository's `.claude/skills/`**. ... Plugins enabled only in your user settings don't load in cloud sessions." — [code.claude.com: Skills, "Use skills in Cowork and cloud sessions"](https://code.claude.com/docs/en/skills)
- VERIFIED — "In those sessions, Claude Code loads the skills enabled for your claude.ai account, **with no setup on your part**... Those skills include the ones you create or turn on in your claude.ai settings, skills your organization provides there, and Anthropic's built-in skills such as `pdf` and `xlsx`." — [code.claude.com: Skills, "Skills synced from claude.ai"](https://code.claude.com/docs/en/skills)
- VERIFIED — Tabla "What carries over from your setup": repo `.claude/skills/`, `.claude/agents/`, `.claude/commands/` → **Yes** ("Part of the clone"); usuario `~/.claude/skills/` → **No** ("Commit them to the repo's `.claude/` directory instead. Cloud sessions automatically load skills you enable on claude.ai"); "Plugins enabled only in your user settings" → **No**; "Marketplaces declared in your repo's `.claude/settings.json`" → **No, in an Anthropic-hosted environment**. — [code.claude.com: Configure cloud environments](https://code.claude.com/docs/en/cloud-environments)
- VERIFIED — Efímero: "Cloud sessions start from a fresh clone of your repository... Anything you've installed or configured only on your own machine isn't available in the session." "after a few minutes without activity, a session's VM pauses with its files saved, and a paused VM can later be reclaimed"; al reabrir se aprovisiona "a fresh VM" y se restaura solo el historial de conversación. — [code.claude.com: Configure cloud environments](https://code.claude.com/docs/en/cloud-environments) y [Use Claude Code in the cloud, "Environment expired"](https://code.claude.com/docs/en/claude-code-on-the-web)
- VERIFIED — Tarjetas de sugerencia: "A card in the conversation that lists one or more plugins, with an **Add** button, means Claude is suggesting plugins for your task... Select **Add** on a plugin to turn it on for your claude.ai account, where it stays on after the session ends. To undo, open the added plugin from the card, select **Manage**..." Las herramientas implicadas se llaman `SearchPlugins` y `SuggestPluginInstall`. — [code.claude.com: Use Claude Code in the cloud, "Plugin suggestions in the conversation"](https://code.claude.com/docs/en/claude-code-on-the-web)
- VERIFIED — `/config` en claude.ai/code abre **Settings > Code** o **Settings > Claude Code** (ajustes de Code, no skills). — [code.claude.com: Use Claude Code in the cloud](https://code.claude.com/docs/en/claude-code-on-the-web)

## 6. Guía de seguridad de Anthropic sobre skills y plugins de terceros

### Takeaway
Anthropic dice explícitamente: usar skills solo de fuentes de confianza (creadas por uno mismo u obtenidas de Anthropic) y auditar todo lo demás antes de activarlo, porque una skill puede traer scripts e instrucciones maliciosas; los plugins pueden además ejecutar código en el ordenador. Solo los plugins del directorio de claude.ai pasan revisión de Anthropic; lo subido a mano o añadido por URL no.

### Cited Findings
- VERIFIED — "Use Skills only from trusted sources: those you created yourself or obtained from Anthropic... a malicious Skill can direct Claude to call tools or run code in ways that don't match the Skill's stated purpose." Advertencia: con una skill de fuente desconocida, "exercise extreme caution and thoroughly audit it before use... could lead to data exfiltration, unauthorized system access". Puntos: auditar todos los archivos (SKILL.md, scripts, imágenes); las skills que traen datos de URLs externas son de riesgo particular; "Treat like installing software". — [platform.claude.com: Agent Skills overview, "Security considerations"](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview)
- VERIFIED — "Only install skills only from trusted sources." "When installing a skill from a less-trusted source—including one shared by a colleague—review it before enabling." "skills may include, or instruct Claude to install, third-party packages and software". Riesgo principal citado: prompt injection. — [Help Center: Use skills in Claude](https://support.claude.com/en/articles/12512180-using-skills-in-claude)
- VERIFIED — "skills someone shares with you or that you upload yourself aren't reviewed by Anthropic, so open the skill and read its `SKILL.md` and files before you turn it on." — [claude.com/docs: Skills overview](https://claude.com/docs/skills/overview)
- VERIFIED — "Anthropic reviews plugins listed in the directory: every version gets automated validation and a security scan, and a person reviews a new listing before it goes live... That review doesn't cover a plugin you add from a marketplace URL or upload yourself, so add those only from sources you trust." — [claude.com/docs: Plugins](https://claude.com/docs/plugins/overview)
- VERIFIED — "Plugins may include local MCP servers that run on your computer with the same permissions as any other program you run." "Only install plugins from sources you trust." — [Help Center: Use plugins in Claude](https://support.claude.com/en/articles/13837440-use-plugins-in-claude)
- VERIFIED — "A Claude Code plugin you install can execute arbitrary code on your machine with your user privileges." Aviso mostrado antes de instalar: "Anthropic does not control what MCP servers, files, or other software are included in plugins and cannot verify that they will work as intended or that they won't change." "Anthropic doesn't review third-party marketplaces". Con auto-update, "the files you reviewed can change on disk". — [code.claude.com: Plugin security and trust](https://code.claude.com/docs/en/plugins/security) y [Anthropic's marketplaces](https://code.claude.com/docs/en/plugins/anthropic-marketplaces)
- VERIFIED — No poner claves ni contraseñas dentro de una skill: "everyone you share the skill with receives its files". — [claude.com/docs: Create custom skills](https://claude.com/docs/skills/how-to)
- VERIFIED — El escaneo automático de contenido malicioso de skills subidas existe solo para Enterprise con "skill scanning" activado. — [Help Center: Use skills in Claude](https://support.claude.com/en/articles/12512180-using-skills-in-claude)

### Inferences
- Escala práctica de confianza: (1) skills integradas y "From Anthropic & Partners" / plugins "Anthropic verified" del directorio; (2) repos de `github.com/anthropics/`; (3) marketplace comunitario (enviado a Anthropic, fijado por commit); (4) repos de terceros y ZIP descargados — leer SKILL.md y scripts antes de activar.
- En chat de claude.ai el riesgo de una skill se limita al sandbox de ejecución de código y a los conectores conectados; en Cowork/Claude Code un plugin con hooks o MCP local puede tocar los archivos del ordenador. Una skill de escritura hecha solo de instrucciones en Markdown (sin `scripts/`) es la de menor riesgo y la más fácil de revisar.

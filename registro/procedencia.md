# Registro de procedencia

Anota aquí, capítulo a capítulo, quién redactó qué. Sirve para declarar con exactitud el uso de IA al publicar y para distinguir la aportación del autor.

| Fecha | Capítulo o archivo | Esquema | Borrador | Edición del autor | Notas |
|---|---|---|---|---|---|
| | | | | | |

Cómo rellenarlo:

- **Esquema:** quién lo propuso y quién lo aprobó.
- **Borrador:** quién redactó la primera versión.
- **Edición del autor:** `ninguna`, `ligera`, `sustancial` o `reescrito`, con una frase sobre qué cambió.
- **Notas:** pasajes escritos íntegramente por el autor, ideas suyas que cambiaron el capítulo, o cualquier otra cosa relevante.

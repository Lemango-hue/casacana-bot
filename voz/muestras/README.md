# Muestras de voz

Aquí van de tres a cinco textos escritos por el autor, uno por archivo (`.md` o `.txt`).

- Sirven textos de cualquier tipo: relatos, cartas, correos largos, publicaciones, apuntes.
- Cuanto más variados, mejor: una escena, una reflexión, algo con diálogo.
- Deben ser textos del autor tal como los escribió, sin corregir.

Claude los lee antes de redactar para ajustar el ritmo, el vocabulario y el tono. No se publican ni se copian en la novela.
